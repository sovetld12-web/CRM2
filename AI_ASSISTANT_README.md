# 🤖 AI-помощник CRM «Команда Роста»

Полноценная интеграция с OpenAI для автоматизации работы с клиентами и бизнес-задачами.

---

## 📋 Два режима работы

### 1. 💬 Чат с AI (свободное общение)

**Для чего:**
- Задавать вопросы по бизнесу, HR, продажам, стратегиям
- Получать советы и идеи
- Анализировать ситуации
- Обсуждать решения
- Генерировать контент

**Примеры запросов:**
- "Помоги разобраться с зависшими вакансиями"
- "Как выстроить систему работы со спящей базой?"
- "Какие метрики отслеживать для агентства?"
- "Придумай контент-план на неделю"
- "Клиент говорит 'дорого'. Как отработать?"
- "Подумай вместе со мной: стоит ли нанимать сотрудника?"

**Особенности:**
- AI выступает как умный собеседник и советник
- Знает контекст вашего бизнеса
- Может задавать уточняющие вопросы
- Помогает думать, а не просто даёт ответы
- Поддерживает режимы: "подумай вместе", "критикуй", "упрости", "разверни"

---

### 2. ✨ Конструктор ответов (специализированный)

**Для чего:**
- Генерировать готовые ответы клиентам с Profi.ru, Avito, hh.ru, Telegram
- Анализировать запросы клиентов
- Создавать продающие сообщения

**Формат ответа:**
1. **Что это за запрос** — анализ ситуации
2. **Готовый ответ клиенту** — текст для копирования
3. **Почему сработает** — объяснение
4. **Следующий шаг** — сообщение для вывода на встречу

**Примеры запросов:**
- "Клиент с Profi.ru: 'Нужен рекрутер для подбора менеджеров. Бюджет 50 000'"
- "Клиент с Avito: 'Ищем HR в штат, полный день, ведение кадров'"
- "Клиент с hh.ru: 'Нужно построить отдел продаж с нуля'"
- "Клиент в Telegram: 'Сколько стоит подобрать главбуха?'"

**Особенности:**
- Специальный промпт для продаж HR-услуг
- Автоматически включает обязательный вопрос: "Подскажите, кроме стоимости, что для вас будет главным критерием?"
- Не продаёт в лоб, а выводит на встречу
- Использует релевантные кейсы
- Кнопка "Копировать ответ" для быстрого использования

## ⚙️ Настройка

### 1. Получите API-ключ OpenAI

1. Перейдите на https://platform.openai.com/api-keys
2. Создайте новый API-ключ
3. Скопируйте его (начинается с `sk-...`)

### 2. Добавьте переменные окружения на Amvera

В настройках проекта на Amvera добавьте:

```env
VITE_OPENAI_API_KEY=sk-your-api-key-here
VITE_OPENAI_MODEL=gpt-4o-mini
```

**Доступные модели:**
- `gpt-4o-mini` — быстрая и экономичная (рекомендуется)
- `gpt-4o` — более мощная, но дороже
- `gpt-4-turbo` — для сложных задач
- `gpt-3.5-turbo` — самая дешёвая

### 3. Перезапустите приложение

После добавления переменных перезапустите проект на Amvera.

## 🔒 Безопасность

### Текущая реализация (простая)

- API-ключ хранится в `VITE_OPENAI_API_KEY`
- Ключ попадает в клиентский код (виден в браузере)
- Подходит для внутреннего использования и тестирования

**⚠️ Важно:** Не используйте этот подход для публичных приложений!

### Рекомендация для продакшена (безопасная)

Создайте backend-прокси на Amvera:

```
Браузер → Ваш backend (Amvera) → OpenAI API
                ↑
        OPENAI_API_KEY (только на сервере)
```

**Преимущества:**
- API-ключ не виден в браузере
- Можно добавить лимиты и логирование
- Легче контролировать расходы

## 💰 Стоимость использования

**Примерные расходы на OpenAI API:**

| Модель | Цена за 1M токенов | Пример на 100 запросов |
|--------|-------------------|------------------------|
| gpt-4o-mini | ~$0.15 | ~$0.50-1.00 |
| gpt-4o | ~$2.50 | ~$5-10 |
| gpt-3.5-turbo | ~$0.50 | ~$1-2 |

**Для вашего случая:**
- Средний запрос: ~500-1000 токенов
- 100 запросов в месяц: ~$1-3 (gpt-4o-mini)
- Это очень экономично!

## 🎯 Как использовать эффективно

### Чат с AI

1. **Будьте конкретны** — чем точнее вопрос, тем лучше ответ
2. **Давайте контекст** — расскажите о ситуации, цифрах, ограничениях
3. **Используйте режимы:**
   - "Подумай вместе со мной" — для стратегических вопросов
   - "Критикуй" — для проверки идей
   - "Упрости" — для объяснений
   - "Разверни" — для глубокого анализа

### Конструктор ответов

1. **Вставляйте полный текст запроса** — чем больше информации, тем лучше
2. **Указывайте площадку** — Profi.ru, Avito, hh.ru, Telegram
3. **Добавляйте контекст** — если есть дополнительные детали
4. **Копируйте готовый ответ** — кнопка "Копировать ответ"
5. **Адаптируйте под себя** — AI даёт основу, вы добавляете личность

## 🛠️ Технические детали

### Структура файлов

```
src/
├── prompts/
│   ├── salesAssistant.ts      # Промпт для конструктора ответов
│   └── chatAssistant.ts       # Промпт для свободного чата
├── services/
│   └── ai.ts                  # Сервис для работы с OpenAI API
├── pages/
│   └── AIAssistant.tsx        # Страница AI-помощника
└── contexts/
    └── ThemeContext.tsx       # Контекст темы
```

### Как это работает

1. Пользователь отправляет сообщение
2. Формируется запрос с системным промптом + историей диалога
3. Запрос отправляется на OpenAI API
4. Ответ отображается в чате
5. История сохраняется для контекста

### Ограничения

- История диалога сбрасывается при перезагрузке страницы
- Максимальная длина ответа: ~2000 токенов
- Нет кэширования ответов
- Нет экспорта истории
