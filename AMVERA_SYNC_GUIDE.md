# 🔄 Синхронизация с Amvera

## 📋 Что произошло

ИИ-агент Amvera внес изменения в архитектуру проекта:
- Добавил серверную часть (Node.js + Express) для безопасной работы с API-ключом OpenAI
- API-ключ теперь на сервере, а не в клиентском коде
- Запросы к OpenAI идут через серверный прокси `/api/openai/chat`

## ✅ Что было синхронизировано

### 1. Создан server.js
Серверный прокси для OpenAI API:
- Принимает запросы на `/api/openai/chat`
- Использует переменную окружения `OPENAI_API_KEY`
- Отдает статические файлы из папки `dist`
- Работает на порту 3000

### 2. Создан amvera.yaml
Конфигурация для Amvera:
- Запуск: `node server.js`
- Порт: 3000
- Переменные: `OPENAI_API_KEY` (обязательна)
- Артефакты: `dist`, `server.js`

### 3. Обновлен src/services/ai.ts
Клиентский код теперь:
- Использует серверный прокси `/api/openai/chat`
- Не содержит API-ключ
- Всегда возвращает `isApiConfigured() = true`

## 🔧 Решение проблем

### Проблема: Ошибка 405 Method Not Allowed

**Причина:** Приложение запускается как статический сайт, а не как Node.js сервер

**Решение:**
1. Проверьте наличие файла `amvera.yaml` в репозитории
2. Убедитесь, что в нем указано:
   ```yaml
   run:
     command: node server.js
   ```
3. Пересоберите проект на Amvera

### Проблема: Cannot find package 'express'

**Причина:** Зависимости не установлены

**Решение:**
1. Проверьте, что в `package.json` есть `express`
2. Если нет, добавьте:
   ```bash
   npm install express
   git add package.json package-lock.json
   git commit -m "chore: add express dependency"
   git push origin master
   ```

### Проблема: API key not configured

**Причина:** Переменная `OPENAI_API_KEY` не настроена на Amvera

**Решение:**
1. Откройте панель управления Amvera
2. Перейдите в раздел **"Переменные"**
3. Добавьте переменную:
   - **Имя:** `OPENAI_API_KEY`
   - **Значение:** `sk-ваш-ключ-openai`
4. Перезапустите приложение

### Проблема: Данные не обновляются

**Причина:** Кэш браузера

**Решение:**
1. Жёсткая перезагрузка: `Ctrl + F5` (Windows/Linux) или `Cmd + Shift + R` (Mac)
2. Очистка кэша через консоль:
   ```javascript
   localStorage.clear(); location.reload();
   ```

## 📊 Проверка работы

### Проверка сервера

Откройте консоль браузера (`F12`) и выполните:

```javascript
fetch('/api/openai/chat', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    model: 'gpt-4o-mini',
    messages: [{ role: 'user', content: 'Привет' }]
  })
}).then(r => r.json()).then(console.log);
```

Если видите ответ от OpenAI — сервер работает правильно.

### Проверка логов

В логах Amvera должно быть:
```
Server is running on 0.0.0.0:3000
```

Если видите ошибки — проверьте:
- Наличие `server.js` в репозитории
- Наличие `amvera.yaml` с правильными настройками
- Наличие переменной `OPENAI_API_KEY`
