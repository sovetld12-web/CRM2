# 🏦 Вкладка "Банк" - Руководство пользователя

## ✅ Что нового

Вкладка "Банк" полностью переработана и теперь работает с реальными данными из CRM.

---

## 📊 Основные возможности

### 1. Группировка по месяцам

Все финансовые операции автоматически группируются по месяцам:

- **Помесячная сводка** — показывает поступления, расходы и чистое движение по каждому месяцу
- **Сортировка** — месяцы отображаются в обратном хронологическом порядке (новые сверху)
- **Быстрая навигация** — кликните на месяц, чтобы увидеть все операции за этот период

### 2. Фильтрация по месяцу

- **Кнопка "Все месяцы"** — показывает все операции без фильтрации
- **Выбор конкретного месяца** — показывает только операции за выбранный месяц
- **Счётчик операций** — показывает количество операций в выбранном периоде

### 3. Общая сводка

В верхней части вкладки отображаются ключевые показатели:

- **Операций** — общее количество финансовых операций
- **Поступления** — общая сумма всех поступлений (зелёный)
- **Расходы** — общая сумма всех расходов (красный)
- **Кредиты** — сумма кредитных операций
- **Вывод на карту** — сумма выводов на личную карту
- **Чистое движение** — разница между поступлениями и расходами

## 📥 Импорт финансовых операций

### Автоматическое определение типа операции

При импорте из старой CRM система автоматически определяет, является ли операция поступлением или расходом:

#### 1. По полю `type`
- `расход`, `expense`, `outcome` → **Расход**
- `поступление`, `income`, `revenue` → **Поступление**

#### 2. По знаку суммы
- Отрицательная сумма (например, `-15000`) → **Расход**
- Положительная сумма (например, `60000`) → **Поступление**

#### 3. По категории
- Содержит `расход`, `оплата`, `вывод` → **Расход**
- Содержит `поступление`, `оплата от` → **Поступление**

### Пример импорта

**Из старой CRM:**
```json
{
  "date": "2026-09-02",
  "type": "Поступление",
  "counterparty": "ИП Браун И.В.",
  "category": "Поступление клиента",
  "sum": 60000,
  "description": "Счет №84 от 02.09.2026"
}
```

**Конвертируется в:**
```json
{
  "id": "tx_1234567890",
  "date": "2026-09-02",
  "type": "income",
  "counterparty": "ИП Браун И.В.",
  "category": "Поступление клиента",
  "sum": 60000,
  "description": "Счет №84 от 02.09.2026"
}
```

**Отображается как:**
- Тип: 🟢 Поступление
- Сумма: +60 000 ₽ (зелёным)

## 🎯 Как использовать

### Просмотр всех операций

1. Откройте вкладку **"Банк"**
2. Убедитесь, что выбрана кнопка **"Все месяцы"**
3. Просматривайте все операции в таблице

### Просмотр операций за конкретный месяц

1. Откройте вкладку **"Банк"**
2. В блоке **"Помесячная сводка"** кликните на нужный месяц
3. Таблица отфильтруется и покажет только операции за выбранный месяц
4. Для возврата ко всем операциям кликните **"Все месяцы"**

### Анализ финансового состояния

1. Посмотрите на **общую сводку** в верхней части:
   - Поступления vs Расходы
   - Чистое движение (прибыль/убыток)
   - Кредиты и выводы на карту

2. Изучите **помесячную сводку**:
   - Какие месяцы были прибыльными (зелёный результат)
   - Какие месяцы были убыточными (красный результат)
   - Динамика поступлений и расходов

3. Проверьте **детали операций**:
   - Кто основные контрагенты
   - Какие категории расходов преобладают
   - Есть ли необычные операции

## 📊 Примеры использования

### Пример 1: Анализ прибыльности месяца

1. Откройте вкладку "Банк"
2. Найдите месяц в помeseчной сводке
3. Посмотрите на результат:
   - 🟢 Зелёный — месяц прибыльный
   - 🔴 Красный — месяц убыточный
4. Кликните на месяц, чтобы увидеть детали
5. Проанализируйте операции:
   - Какие поступления были основными
   - Какие расходы можно оптимизировать

### Пример 2: Поиск крупных расходов

1. Откройте вкладку "Банк"
2. Выберите "Все месяцы"
3. Отсортируйте таблицу по сумме (если доступно)
4. Или просмотрите все операции и найдите крупные расходы
5. Проверьте категории расходов

### Пример 3: Отслеживание поступлений от клиента

1. Откройте вкладку "Банк"
2. Выберите нужный месяц
3. Найдите операции с нужным контрагентом
4. Проверьте все поступления от этого клиента

## 🔍 Решение проблем

### Проблема: Все операции отображаются как расходы

**Причина:** Старые данные были импортированы до исправления логики определения типа

**Решение:**
1. Откройте вкладку "💾 Управление данными"
2. Экспортируйте текущие данные
3. Очистите данные:
   ```javascript
   localStorage.removeItem('crm_money');
   ```
4. Перезагрузите страницу
5. Импортируйте данные заново из файла старой CRM

### Проблема: Нет данных во вкладке "Банк"

**Причина:** Финансовые операции не были импортированы

**Решение:**
1. Проверьте, есть ли данные в файле старой CRM (`data.bankTransactions`)
2. Импортируйте данные заново
3. Проверьте консоль браузера (F12) на наличие ошибок

### Проблема: Неправильные суммы

**Причина:** Суммы могут быть отрицательными в исходных данных

**Решение:**
- Система автоматически берёт абсолютное значение суммы
- Тип операции определяется по другим признакам (type, категория)
- Если суммы всё равно неправильные, проверьте исходные данные
