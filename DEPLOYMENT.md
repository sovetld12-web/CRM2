# Инструкция по развертыванию на Amvera

## 📋 Требования

- Аккаунт на [Amvera.io](https://amvera.io)
- Git-репозиторий с проектом
- API-ключ OpenAI (опционально)

---

## 🚀 Пошаговая инструкция

### 1. Подготовка проекта

Убедитесь, что в корне проекта есть файлы:

```
├── package.json
├── vite.config.ts
├── tsconfig.json
├── index.html
├── src/
│   ├── main.tsx
│   ├── App.tsx
│   ├── index.css
│   └── ...
└── public/
    └── ...
```

### 2. Настройка переменных окружения

Создайте файл `.env` в корне проекта (опционально):

```bash
# OpenAI API (опционально)
VITE_OPENAI_API_KEY=sk-your-api-key-here
VITE_OPENAI_MODEL=gpt-4o-mini
```

**Важно:** Переменные с префиксом `VITE_` будут доступны в клиентском коде.

### 3. Сборка проекта

```bash
# Установка зависимостей
npm install

# Сборка для продакшена
npm run build
```

Результат сборки находится в папке `dist/`.

### 4. Развертывание на Amvera

#### Вариант A: Статический сайт (рекомендуется)

1. Зайдите в панель управления Amvera
2. Создайте новое приложение → **Static**
3. Выберите репозиторий с проектом
4. Настройте сборку:
   - **Build command:** `npm run build`
   - **Output directory:** `dist`
5. Добавьте переменные окружения (если нужно):
   - `VITE_OPENAI_API_KEY` = `sk-...`
   - `VITE_OPENAI_MODEL` = `gpt-4o-mini`
6. Нажмите **Deploy**

#### Вариант B: Node.js приложение

1. Зайдите в панель управления Amvera
2. Создайте новое приложение → **Node.js**
3. Выберите репозиторий с проектом
4. Настройте:
   - **Start command:** `npm run preview`
   - **Port:** `3000`
5. Добавьте переменные окружения
6. Нажмите **Deploy**

### 5. Проверка

После развертывания:

1. Откройте URL приложения
2. Проверьте, что все вкладки работают
3. Проверьте загрузку данных из старой CRM
4. Проверьте AI-помощник (если настроен API-ключ)

## 🔧 Настройка OpenAI API

### Получение API-ключа

1. Зайдите на [platform.openai.com](https://platform.openai.com)
2. Перейдите в раздел **API keys**
3. Нажмите **Create new secret key**
4. Скопируйте ключ (начинается с `sk-...`)

### Настройка в Amvera

1. Откройте настройки приложения
2. Перейдите в раздел **Environment variables**
3. Добавьте переменные:
   - **Name:** `VITE_OPENAI_API_KEY`
   - **Value:** `sk-your-api-key-here`
4. Добавьте (опционально):
   - **Name:** `VITE_OPENAI_MODEL`
   - **Value:** `gpt-4o-mini`
5. Сохраните и перезапустите приложение

### Альтернативный способ

API-ключ можно ввести прямо в интерфейсе CRM:

1. Откройте вкладку **"AI-помощник"**
2. Нажмите **"Настройки"** (⚙️)
3. Введите API-ключ в поле **"API-ключ OpenAI"**
4. Нажмите **"Сохранить"**

Ключ сохранится в localStorage браузера.

## 🔒 Безопасность

### API-ключ OpenAI

**Важно:** API-ключ OpenAI виден в клиентском коде!

**Рекомендации:**

1. **Для продакшена** используйте backend-прокси:
   - Создайте Node.js сервер на Amvera
   - Храните API-ключ только на сервере
   - Фронтенд обращается к вашему серверу
   - Сервер пересылает запросы в OpenAI

2. **Ограничьте использование ключа:**
   - Установите лимиты в OpenAI Dashboard
   - Используйте отдельный ключ для продакшена
   - Регулярно ротируйте ключи

3. **Альтернатива:** Позвольте пользователям вводить свой API-ключ через интерфейс

### Данные пользователей

Все данные хранятся в **localStorage** браузера пользователя:

- ✅ Данные не передаются на сервер
- ✅ Каждый пользователь видит только свои данные
- ✅ Данные сохраняются между сессиями
- ⚠️ Данные привязаны к браузеру и устройству

**Рекомендация:** Регулярно делайте экспорт данных через вкладку "Загрузка данных".

## 🐛 Решение проблем

### Проблема: AI-помощник не работает

**Решение:**

1. Проверьте, что API-ключ настроен:
   - В переменных окружения Amvera
   - Или в настройках AI-помощника
2. Проверьте консоль браузера (F12) на ошибки
3. Убедитесь, что ключ действителен на [platform.openai.com](https://platform.openai.com)

### Проблема: Данные не загружаются

**Решение:**

1. Проверьте формат JSON файла
2. Откройте консоль браузера (F12)
3. Посмотрите лог импорта на странице "Загрузка данных"
4. Убедитесь, что файл не поврежден

### Проблема: Данные не сохраняются

**Решение:**

1. Проверьте, что localStorage не отключен в браузере
2. Очистите кэш браузера
3. Попробуйте в режиме инкогнито
4. Проверьте консоль на ошибки

### Проблема: Мобильная версия не работает

**Решение:**

1. Очистите кэш браузера
2. Проверьте, что включен JavaScript
3. Попробуйте другой браузер
4. Проверьте консоль на ошибки
