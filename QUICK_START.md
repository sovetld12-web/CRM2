## 🔄 Автоматическая конвертация полей

Система автоматически конвертирует поля из старого формата в новый:

| Старое поле | Новое поле | Описание |
|-------------|------------|----------|
| `amount` | `sum` | Сумма сделки/проекта |
| `nextDate` | `nextStepDate` | Дата следующего шага |
| `owner` | `responsible` | Ответственный |
| `note` | `comment` | Комментарий |
| `contactHandle` | `phone` | Телефон / ник |

| `company` | `client` | Клиент (для проектов) |

## ❓ Если что-то не работает

### Проблема: "Не удалось определить тип данных"

**Решение:**
1. Обновите страницу (Ctrl+F5)
2. Убедитесь, что файл имеет расширение `.json`
3. Проверьте, что файл не повреждён
4. Попробуйте загрузить через вкладку "💾 Управление данными"

**Решение:**
1. Перезагрузите страницу (Ctrl+F5)
2. Очистите кэш браузера
3. Проверьте localStorage (см. выше)
4. Попробуйте в режиме инкогнито

### Проблема: Некоторые поля пустые

**Решение:**
1. Проверьте лог импорта в консоли
2. Убедитесь, что поля есть в исходном файле
3. Проверьте маппинг полей (таблица выше)

## 📊 Что импортируется

### Лиды (data.leads)

**Пример записи:**
```json
{
  "id": "molmkwlcm5bk9f",
  "date": "2026-04-28",
  "company": "",
  "contact": "@antonina_vladii",
  "contactHandle": "",
  "source": "Аномалия",
  "stage": "Отказ",
  "product": "Рекрутинг",
  "amount": 80000,
  "paid": 0,
  "project": "",
  "nextStep": "написать в ТГ",
  "nextDate": "2026-05-04",
  "owner": "",
  "comment": ""
}
```

**Конвертируется в:**
```json
{
  "id": "molmkwlcm5bk9f",
  "date": "2026-04-28",
  "company": "",
  "contact": "@antonina_vladii",
  "phone": "",
  "source": "Аномалия",
  "stage": "Отказ",
  "product": "Рекрутинг",
  "sum": 80000,
  "paid": 0,
  "project": "",
  "nextStep": "написать в ТГ",
  "nextStepDate": "2026-05-04",
  "responsible": "Любовь",
  "comment": "",
  "createdAt": "2026-04-28"
}
```

### Спящая база (data.sleepingLeads)

**Конвертируется аналогично лидам, но с дополнительными полями:**
- `ltv` — пожизненная ценность клиента
- `lastContactDate` — дата последнего контакта

### Проекты (data.orders)

**Конвертируется в:**
- `client` — клиент
- `vacancy` — вакансия/проект
- `sum` — сумма проекта
- `status` — статус (В работе, На паузе, Закрыт)
- `startDate` — дата начала

### Финансовые операции (data.bankTransactions)

**Конвертируется в:**
- `date` — дата операции
- `type` — тип (income/expense)
- `counterparty` — контрагент
- `category` — категория
- `sum` — сумма
- `description` — описание
