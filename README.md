# CRM Команда Роста

Современная CRM-система для HR-агентства с интеграцией AI-помощника.

## 🚀 Возможности

### Основные модули

- **📊 Центр управления** — дашборд с ключевыми метриками, графиками и AI-наставником
- **👥 Лиды** — управление лидами с карточками клиентов и компаний
- **🏭 Производство** — активные проекты и вакансии в работе
- **💰 Деньги** — финансовые операции (поступления и расходы)
- **✅ Задачи** — управление задачами с приоритетами
- **📋 Счета** — выставление и отслеживание счетов
- **💸 Затраты** — учет расходов по категориям
- **🏦 Банк** — банковские операции и выписки
- **📈 Маркетинг** — анализ каналов привлечения, CPL, ROMI, LTV
- **🤖 AI-помощник** — два режима:
  - **Чат с AI** — свободное общение, советы, идеи
  - **Конструктор ответов** — генерация ответов клиентам с автоматическим созданием лидов
- **📄 Документы** — генератор договоров и актов
- **😴 Спящая база** — клиенты для повторных касаний с расчетом LTV
- **📥 Загрузка данных** — импорт/экспорт данных из старой CRM

### Ключевые функции

✅ **Drag-and-drop** для изменения порядка вкладок  
✅ **Детализация** по двойному клику на KPI-карточки  
✅ **Глобальный фильтр периода** — выбор любого месяца и года  
✅ **Автоматические переходы** — лид → производство → спящая база  
✅ **Расчет LTV** — автоматический подсчет пожизненной ценности клиента  
✅ **AI-интеграция** — OpenAI API для генерации ответов  
✅ **Темная/светлая тема** — переключатель в боковом меню  
✅ **Мобильная версия** — адаптивный интерфейс для всех устройств  
✅ **localStorage** — все данные сохраняются автоматически

## 📥 Загрузка данных из старой CRM

### Формат данных

CRM поддерживает импорт данных из старой CRM в формате JSON. Файл должен иметь структуру:

```json
{
  "app": "CRM Команда роста",
  "format": "agency-crm-json",
  "version": 2,
  "exportedAt": "2026-09-08T14:50:27.197Z",
  "counts": {
    "leads": 116,
    "sleepingLeads": 101,
    "orders": 38,
    "bankTransactions": 341,
    "tasks": 15
  },
  "data": {
    "leads": [...],
    "sleepingLeads": [...],
    "orders": [...],
    "bankTransactions": [...],
    "tasks": [...]
  }
}
```

### Как загрузить данные

1. Откройте вкладку **"Загрузка данных"** (вторая в боковом меню, зелёная иконка ☁️)
2. Нажмите **"Загрузить JSON"** или перетащите файл в зону загрузки
3. Система автоматически:
   - Определит формат данных
   - Конвертирует из старого формата в новый
   - Сохранит все данные в localStorage
   - Перезагрузит страницу

### Автоматическая конвертация полей

Система автоматически маппит поля из старого формата:

| Старое поле | Новое поле |
|-------------|------------|
| `amount` | `sum` |
| `nextDate` | `nextStepDate` |
| `owner` | `responsible` |
| `note` | `comment` |
| `contactHandle` | `phone` |
| `lastTouchDate` | `lastContactDate` |

### Поддерживаемые типы данных

- ✅ **Лиды** (`data.leads`) — все лиды с контактами, этапами, суммами
- ✅ **Спящая база** (`data.sleepingLeads`) — завершенные клиенты для повторных касаний
- ✅ **Заказы/Проекты** (`data.orders`) — активные проекты и вакансии
- ✅ **Банковские транзакции** (`data.bankTransactions`) — поступления и расходы
- ✅ **Задачи** (`data.tasks`) — задачи с приоритетами и сроками

## 🤖 AI-помощник

### Настройка API-ключа

1. Откройте вкладку **"AI-помощник"**
2. Нажмите **"Настройки"** (⚙️)
3. Введите API-ключ OpenAI в поле **"API-ключ OpenAI"**
4. Нажмите **"Сохранить"**
5. Страница перезагрузится

**Получить ключ:** [platform.openai.com/api-keys](https://platform.openai.com/api-keys)

### Режимы работы

#### 💬 Чат с AI
- Свободное общение с AI-советником
- Анализ бизнес-ситуаций
- Генерация идей и стратегий
- Помощь в принятии решений

#### ✨ Конструктор ответов
1. Заполните форму информации о клиенте:
   - Дата обращения
   - Имя контакта
   - Компания
   - Телефон / ник
   - Источник
   - Продукт
   - Сумма / чек
   - Проект / вакансия

2. Вставьте текст запроса клиента
3. Нажмите **Enter** или кнопку отправки
4. ✅ **Лид автоматически создаётся** и попадает во вкладку "Лиды"
5. AI генерирует готовый ответ клиенту

## 📊 Дашборд

### Компактная верхняя часть

- KPI-карточки: Лиды, Продажи, Конверсия, Поступления, Потенциал
- AI-наставник с рекомендациями
- Все данные фильтруются по глобальному периоду (месяц/год)

### Сворачиваемые accordion-блоки

1. **План на месяц** (раскрыт по умолчанию)
   - Таблица с показателями: Лиды, Продажи, Конверсия, Сумма продаж, Поступления, Маржа, Затраты
   - Кнопка **"Подставить среднее"** — рассчитывает средние за последние 3/6/12 месяцев
   - Ручное редактирование плана
   - Кнопка **"Сохранить план"**

2. **Подробный план-факт-прогноз** (свёрнут по умолчанию)
   - Таблица с метриками: План / Факт / Прогноз / Отклонение / Статус
   - Прогноз рассчитывается линейной экстраполяцией
   - Статусы: 🟢 По плану (≥90%), 🟡 Риск (70-89%), 🔴 Отставание (<70%)

3. **История показателей по месяцам** (свёрнута по умолчанию)
   - Таблица за последние 12 месяцев
   - Колонки: Месяц, Лиды, Сделки, Конверсия, Сумма продаж, Поступления, Затраты

4. **Дорожная карта** (свёрнута, заглушка)
   - Зарезервирована архитектура для будущей реализации

## 🔄 Автоматические переходы

### Логика работы CRM

```
Клиент обратился
    ↓
создается Лид
    ↓
проводятся переговоры
    ↓
клиент покупает услугу
    ↓
создается Проект в Производстве
    ↓
проект реализуется
    ↓
фиксируются сумма, сроки, затраты, результат
    ↓
проект получает статус Реализован
    ↓
клиент попадает в Спящую базу
    ↓
CRM считает дни без контакта и дату следующего касания
    ↓
клиент снова проявляет интерес
    ↓
создается новый Лид того же клиента
    ↓
при продаже создается новый проект
    ↓
LTV клиента увеличивается
```

## 💾 Хранение данных

Все данные сохраняются в **localStorage** браузера:

- `crm_leads` — лиды
- `crm_projects` — проекты
- `crm_tasks` — задачи
- `crm_money` — финансовые операции
- `crm_sleeping` — спящая база
- `crm_menu_order` — порядок вкладок в меню
- `crm_period` — выбранный период (месяц/год)
- `openai_api_key` — API-ключ OpenAI

**Рекомендация:** Регулярно делайте экспорт данных через вкладку "Загрузка данных".
