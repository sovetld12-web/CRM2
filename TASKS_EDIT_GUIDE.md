# ✅ Редактирование задач

## 🎯 Что нового

Теперь вы можете редактировать все параметры задач: название, приоритет и срок выполнения.

---

## ✏️ Как редактировать задачу

### Шаг 1: Найдите задачу

1. Откройте вкладку **"Задачи"**
2. Найдите задачу в списке
3. Используйте фильтры для быстрого поиска:
   - **Все** — показать все задачи
   - **Открытые** — показать только невыполненные задачи
   - **Выполненные** — показать только выполненные задачи

### Шаг 2: Откройте редактирование

Кликните на иконку **карандаша** (✏️) справа от задачи

### Шаг 3: Измените данные

В модальном окне вы можете изменить:

#### 1. Название задачи
- Полное описание задачи
- Например: "Позвонить клиенту Ивану Иванову", "Подготовить коммерческое предложение"

#### 2. Приоритет
- **Нормально** — обычная задача (синий бейдж)
- **Важно** — важная задача (жёлтый бейдж)
- **Критично** — критическая задача (красный бейдж)

#### 3. Срок выполнения
- Дата, до которой задача должна быть выполнена
- Формат: ГГГГ-ММ-ДД

### Шаг 4: Сохраните изменения

Нажмите **"Сохранить"** — изменения применятся немедленно

---

## 🗑️ Удаление задачи

В модальном окне редактирования есть кнопка **"Удалить"** для удаления задачи.

**Внимание:** Удалённые задачи нельзя восстановить!

---

## 🔄 Примеры использования

### Пример 1: Изменение приоритета

**Проблема:** Задача была создана с приоритетом "Нормально", но стала срочной

**Решение:**
1. Найдите задачу в списке
2. Кликните на иконку карандаша
3. Измените приоритет с "Нормально" на "Критично"
4. Нажмите "Сохранить"

**Результат:** Задача теперь отображается с красным бейджем "Критично"

### Пример 2: Продление срока

**Проблема:** Не успеваете выполнить задачу к сроку

**Решение:**
1. Найдите задачу
2. Кликните на иконку карандаша
3. Измените дату срока выполнения
4. Нажмите "Сохранить"

**Результат:** Срок выполнения обновлён

### Пример 3: Уточнение названия

**Проблема:** Название задачи слишком общее

**Решение:**
1. Найдите задачу
2. Кликните на иконку карандаша
3. Уточните название задачи
4. Нажмите "Сохранить"

**Результат:** Название обновлено, задача стала более понятной

## 📊 Статистика задач

В верхней части вкладки отображаются:

- **Открыто** — количество невыполненных задач
- **Критично** — количество критических задач
- **Выполнено** — количество выполненных задач

Эти счётчики обновляются автоматически при изменении задач.

## 💡 Советы

### Регулярный обзор задач

Раз в день проверяйте:
1. Какие задачи стали критическими
2. Какие задачи приближаются к сроку выполнения
3. Какие задачи можно делегировать или удалить

### Использование приоритетов

- **Критично** — задачи, которые нужно выполнить сегодня
- **Важно** — задачи, которые нужно выполнить на этой неделе
- **Нормально** — задачи, которые можно выполнить позже

### Фильтрация задач

Используйте фильтры для быстрого доступа:
- **Открытые** — для работы с текущими задачами
- **Выполненные** — для анализа выполненных задач
- **Все** — для полного обзора

## 🔍 Решение проблем

### Проблема: Задача не редактируется

**Решение:**
1. Обновите страницу (Ctrl+F5)
2. Попробуйте снова
3. Проверьте консоль браузера (F12) на ошибки

### Проблема: Изменения не сохраняются

**Решение:**
1. Убедитесь, что все обязательные поля заполнены
2. Проверьте формат даты (ГГГГ-ММ-ДД)
3. Попробуйте снова

### Проблема: Задача не удаляется

**Решение:**
1. Подтвердите удаление в диалоговом окне
2. Обновите страницу (Ctrl+F5)
3. Проверьте, что задача действительно удалена

## 📈 Автоматические задачи

Некоторые задачи создаются автоматически:

### CRM-задачи
- Создаются при определённых событиях в CRM
- Например: "Выставить счет и акт" при завершении проекта
- Помечены бейджем **CRM**

### AI-задачи
- Создаются AI-наставником на основе анализа данных
- Например: "Провести разбор зависших лидов"
- Помечены бейджем **AI**

### Ручные задачи
- Создаются пользователем вручную
- Не имеют специальных бейджей
