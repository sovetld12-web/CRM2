## 1. Общее описание проекта

### 1.1. Название проекта
**CRM система "Команда Роста"** — система управления клиентами и проектами для HR-агентства.

### 1.2. Назначение системы
CRM система предназначена для:
- Управления лидами и клиентами
- Отслеживания проектов и задач
- Управления финансами (поступления, расходы, предоплаты, постоплаты)
- Аналитики и отчётности
- Автоматизации бизнес-процессов
- Интеграции с AI-помощником для генерации ответов клиентам

### 1.3. Целевая аудитория
- HR-менеджеры
- Рекрутеры
- Руководители HR-агентств
- Финансовые менеджеры

### 1.4. Основные пользователи
- **Администратор** — полный доступ ко всем функциям
- **Менеджер** — доступ к лидам, проектам, задачам
- **Финансовый менеджер** — доступ к финансовым модулям

---

## 2. Цели и задачи

### 2.1. Бизнес-цели
1. **Централизация данных** — все данные о клиентах, проектах и финансах в одной системе
2. **Автоматизация процессов** — автоматическое создание задач, расчёт метрик, генерация отчётов
3. **Улучшение конверсии** — отслеживание воронки продаж и выявление узких мест
4. **Контроль финансов** — прозрачность поступлений и расходов
5. **AI-ассистент** — помощь в генерации ответов клиентам

### 2.2. Функциональные задачи
1. Управление лидами (создание, редактирование, удаление, фильтрация)
2. Управление проектами (создание, редактирование, удаление, статусы)
3. Управление задачами (создание, редактирование, удаление, приоритеты)
4. Управление финансами (поступления, расходы, предоплаты, постоплаты)
5. Аналитика и отчётность (графики, метрики, KPI)
6. Импорт/экспорт данных (JSON, CSV)
7. AI-помощник (генерация ответов, анализ данных)
8. Управление документами (договоры, акты)

## 3. Архитектура системы

### 3.1. Технологический стек
- **Frontend:** React 18 + TypeScript
- **Стилизация:** Tailwind CSS 4
- **Сборка:** Vite 6
- **Графики:** Recharts
- **Drag-and-drop:** @dnd-kit
- **Хранение данных:** localStorage (клиентское хранение)
- **Backend:** Node.js (серверный прокси для OpenAI API)

1. **Компонентный подход** — переиспользуемые компоненты
2. **Context API** — управление состоянием приложения
3. **Модульность** — каждый модуль независим

6. **Безопасность** — API-ключи на сервере, не в клиентском коде

```typescript
interface Lead {
  id: string;

  nextStepDate: string;      // Дата следующего шага
  responsible: string;       // Ответственный
  comment: string;           // Комментарий
```

#### 6.1.2. Project (Проект)
```typescript
interface Project {
  id: string;

  sum: number;               // Сумма проекта

  sourceLeadId?: string;     // ID исходного лида
```

### 6.2. Хранение данных

#### 6.2.1. localStorage
Все данные хранятся в localStorage браузера:

```javascript
localStorage.setItem('crm_leads', JSON.stringify(leads));
localStorage.setItem('crm_projects', JSON.stringify(projects));
localStorage.setItem('crm_tasks', JSON.stringify(tasks));
localStorage.setItem('crm_money', JSON.stringify(moneyOperations));
localStorage.setItem('crm_sleeping', JSON.stringify(sleepingClients));
```

#### 6.2.2. Ключи localStorage
- `crm_leads` — лиды
- `crm_projects` — проекты
- `crm_tasks` — задачи
- `crm_money` — финансовые операции
- `crm_sleeping` — спящая база
- `crm_menu_order` — порядок вкладок
- `crm_period` — выбранный период
- `theme` — тема (dark/light)
- `openai_api_key` — API-ключ OpenAI (устарело, теперь на сервере)

#### 6.2.3. Ограничения
- Размер: ~5-10 MB (зависит от браузера)
- Доступ: только в рамках одного домена
- Синхронизация: нет (данные локальные)

**Рекомендация:** Регулярно делать экспорт данных через модуль "Управление данными".

### 6.3. Валидация данных

#### 6.3.1. Обязательные поля
- **Лид:** contact, source, stage, product
- **Проект:** client, vacancy, sum, status, startDate
- **Задача:** title, priority, dueDate
- **Финансовая операция:** date, type, counterparty, category, sum
- **Спящая база:** client, contact, source, product, project

#### 6.3.2. Форматы данных
- **Дата:** ISO 8601 (YYYY-MM-DD) или локальный формат (DD.MM.YYYY)
- **Сумма:** число (number)
- **Процент:** число от 0 до 100

## 13. Глоссарий

- **CRM** — Customer Relationship Management (система управления клиентами)
- **Лид** — потенциальный клиент
- **Воронка продаж** — этапы от лида до продажи
- **Конверсия** — процент лидов, ставших клиентами
- **LTV** — Lifetime Value (пожизненная ценность клиента)
- **CPL** — Cost Per Lead (стоимость лида)
- **CAC** — Customer Acquisition Cost (стоимость привлечения клиента)
- **ROMI** — Return on Marketing Investment (окупаемость маркетинга)
- **API** — Application Programming Interface (программный интерфейс)
- **UI/UX** — User Interface / User Experience (интерфейс/опыт пользователя)
- **localStorage** — хранилище данных в браузере
- **Context API** — механизм управления состоянием в React
- **TypeScript** — типизированный JavaScript
- **Vite** — инструмент сборки
- **Tailwind CSS** — utility-first CSS фреймворк
- **Recharts** — библиотека для графиков
- **Amvera** — платформа для хостинга
