# 🔄 Обновление и очистка кэша

## ❓ Почему не видны изменения?

Если вы не видите изменений после обновления CRM, это может быть связано с кэшем браузера или старыми данными в localStorage.

---

## ✅ Решение 1: Очистка кэша браузера

### Способ 1: Жёсткая перезагрузка

**Windows/Linux:**
- Нажмите `Ctrl + F5` или `Ctrl + Shift + R`

**Mac:**
- Нажмите `Cmd + Shift + R`

### Способ 2: Очистка кэша через настройки

**Chrome:**
1. Нажмите `F12` или `Ctrl + Shift + I`
2. Перейдите на вкладку "Application" (Приложение)
3. В左侧 меню выберите "Storage" (Хранилище)
4. Нажмите "Clear site data" (Очистить данные сайта)
5. Обновите страницу (`F5`)

**Firefox:**
1. Нажмите `F12` или `Ctrl + Shift + I`
2. Перейдите на вкладку "Storage" (Хранилище)
3. Нажмите "Clear All" (Очистить всё)
4. Обновите страницу (`F5`)

**Safari:**
1. Откройте "Develop" (Разработка) → "Show Web Inspector" (Показать Web Inspector)
2. Перейдите на вкладку "Storage" (Хранилище)
3. Нажмите "Delete All" (Удалить всё)
4. Обновите страницу (`Cmd + R`)

---

## ✅ Решение 2: Очистка localStorage

### Способ 1: Через консоль браузера

1. Откройте консоль браузера (`F12`)
2. Перейдите на вкладку "Console" (Консоль)
3. Выполните команду:

```javascript
localStorage.clear();
location.reload();
```

4. Страница перезагрузится с чистыми данными

### Способ 2: Очистка только данных CRM

Если вы хотите сохранить другие данные, выполните:

```javascript
// Очистка только данных CRM
localStorage.removeItem('crm_leads');
localStorage.removeItem('crm_projects');
localStorage.removeItem('crm_tasks');
localStorage.removeItem('crm_money');
localStorage.removeItem('crm_sleeping');
localStorage.removeItem('crm_menu_order');
localStorage.removeItem('crm_period');

// Перезагрузка страницы
location.reload();
```

---

## ✅ Решение 3: Режим инкогнито

Откройте CRM в режиме инкогнито:

**Chrome:**
- `Ctrl + Shift + N` (Windows/Linux)
- `Cmd + Shift + N` (Mac)

**Firefox:**
- `Ctrl + Shift + P` (Windows/Linux)
- `Cmd + Shift + P` (Mac)

**Safari:**
- `Cmd + Shift + N` (Mac)

В режиме инкогнито не используется кэш и localStorage, поэтому вы увидите самую свежую версию.

---

## ✅ Решение 4: Проверка версии

После обновления проверьте версию приложения:

1. Откройте консоль браузера (`F12`)
2. Найдите сообщение: `🚀 CRM Команда Роста v1.0.4`
3. Если версия старая, очистите кэш (см. выше)

---

## 📋 Что делать после очистки

После очистки кэша и localStorage:

1. **Загрузите данные из старой CRM:**
   - Откройте вкладку "💾 Управление данными"
   - Нажмите "Загрузить JSON"
   - Выберите файл `crm-komanda-rosta-2026-09-08.json`
   - Дождитесь импорта (2-3 секунды)

2. **Проверьте все функции:**
   - ✅ Динамичный график на дашборде
   - ✅ Редактирование финансовых операций
   - ✅ Редактирование задач
   - ✅ Группировка операций по месяцам
   - ✅ Цветовая индикация (поступления зелёным, расходы красным)

3. **Настройте API-ключ OpenAI (если нужен):**
   - Откройте вкладку "AI-помощник"
   - Нажмите "Настройки" (⚙️)
   - Введите API-ключ OpenAI
   - Нажмите "Сохранить"

## 🔍 Проверка новых функций

### Динамичный график

1. Откройте вкладку "Центр управления"
2. Найдите блок "Динамика показателей"
3. Кликайте на кнопки метрик для выбора
4. Переключайте тип графика (Линейный/Столбчатый)

1. Откройте вкладку "Банк"
2. Найдите любую операцию
3. Кликните на иконку карандаша (✏️)
4. Измените данные и сохраните

### Редактирование задач

1. Откройте вкладку "Задачи"
2. Найдите любую задачу
3. Кликните на иконку карандаша (✏️)
4. Измените данные и сохраните

## ❗ Если ничего не помогло

Если после всех действий изменения всё равно не видны:

1. **Попробуйте другой браузер:**
   - Chrome → Firefox
   - Firefox → Safari
   - Safari → Edge

2. **Проверьте подключение к интернету:**
   - Убедитесь, что нет проблем с сетью
   - Попробуйте перезагрузить роутер

3. **Обратитесь в поддержку:**
   - Опишите проблему
   - Укажите версию браузера
   - Приложите скриншоты
